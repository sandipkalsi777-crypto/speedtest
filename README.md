# Internet Speed Test

Frontend: `public/index.html`
Backend (Vercel Edge Functions): `api/ping.js`, `api/download.js`, `api/upload.js`, `api/info.js`

## Deploy
1. Is folder ko GitHub repo mein push karein.
2. vercel.com -> Add New -> Project -> repo import karein.
3. Framework Preset: "Other". Build Command aur Output Directory khaali chhodein. Deploy dabayein.

CLI se: `npm i -g vercel` phir is folder mein `vercel --prod`.
